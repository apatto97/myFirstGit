# My First Git
### Description:
This project was created to introduce Git and put it into practice. 

### Installation instructions: 
1. Clone or download the repository.
2. Confirm project files were copied successfully.

### Run intructions: 
1. Open the program file
2. Select the 'index.html' file.
3. Use node to execute the program.
